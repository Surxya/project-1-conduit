# Conduit - Full-Stack Conduit Dockerized Application

A multi-tier microservices architecture running the Conduit application, fully containerized using Docker Compose.

## 🏗️ Tech Stack

* **Frontend:** React (SPA)
* **Backend:** Node.js (Express API)
* **Database:** PostgreSQL
* **Orchestration:** Docker Compose
